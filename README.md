LOCAL FUT 16

Created by THEKURDISHGUY

A community-made FIFA 16 FUT revival project.

About the Project

LOCAL FUT 16 is a solo-developed project. I have been working on this project alone, without a development team.

The goal is to bring back and improve the FUT 16 experience.

Current Development Status
-⚠️ For now: ONLY Single Player Season works. War in Kurdistan delays dev.
🚀 FUTURE: Online, Draft & all modes!

- Main Menu: Very good and playable.
- Other Features: Still under development.

Future Plans

The project is planned to grow beyond its current offline experience.

Future goals include:
